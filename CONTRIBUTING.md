# Contributing to Taskbar Zones

Open [`taskbar-zones.wh.cpp`](taskbar-zones.wh.cpp) as a local mod in Windhawk. Use the [README](README.md) to set up an example with apps in both taskbar zones.

## Review a change

- Drag a pinned app and a running app between zones. Check relative order after opening and closing an app and after restarting Explorer in a test session.
- For layout or hit-testing changes, check scaling and a secondary display if available. Try an empty zone and one with several apps.
- For settings changes, confirm that applying and reloading the setting keeps the expected grouping and that disabling the mod leaves the taskbar usable.

Include the Windows build, Windhawk version, monitor and scaling setup, and exact drag or app-launch sequence. A short recording is helpful for ordering issues.
